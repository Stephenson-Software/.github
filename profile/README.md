# Stephenson Software

A personal software lab run by Daniel McCoy Stephenson, for projects that do not
fit neatly under Preponderous Software or Dan's Plugins Community.

- Website: https://danielstephenson.dev
- Arcade (browser games): https://danielstephenson.dev/play

## Notable repositories

**Games**

- [arcade](https://github.com/Stephenson-Software/arcade) — one static host for the browser games on the arcade.
- [tak](https://github.com/Stephenson-Software/tak) — a text-adventure kit with console, web and in-browser front-ends.
- [FishE](https://github.com/Stephenson-Software/FishE) — explore a fishing village and perform actions in it.
- [Tidewater](https://github.com/Stephenson-Software/Tidewater), [Overwinter](https://github.com/Stephenson-Software/Overwinter) and [Night-Ferry](https://github.com/Stephenson-Software/Night-Ferry) — text adventures built on tak.

**Developer tooling**

- [gardener](https://github.com/Stephenson-Software/gardener) — a safety-gated CLI that dispatches Claude Code to keep a fleet of repositories aligned with their conventions.
- [create-dev-loop](https://github.com/Stephenson-Software/create-dev-loop) — a Claude Code skill that generates an autonomous development loop for a git repository.
- [Parpt](https://github.com/Stephenson-Software/Parpt) — prioritize software projects using structured metrics.

**Infrastructure and other projects**

- [open-mc-server-infrastructure](https://github.com/Stephenson-Software/open-mc-server-infrastructure) — community-agnostic, Docker-based Minecraft server infrastructure.
- [accordion](https://github.com/Stephenson-Software/accordion) — a self-hosted real-time chat application.

The full list is under [Repositories](https://github.com/orgs/Stephenson-Software/repositories).
